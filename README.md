# رئيس ليبيا (President of Libya)

لعبة محاكاة استراتيجية سياسية واقتصادية باللغة العربية، مبنية بالكامل بـ HTML/CSS/JavaScript بدون أي اعتماديات خارجية أو خطوة بناء (build step).

تتولى دور رئيس ليبيا لفترة رئاسية مدتها 4 سنوات (48 شهراً)، وعليك إدارة الاقتصاد والميزانية والعلاقات الداخلية (القبائل، الأحزاب، المؤسسات) والعلاقات الدولية، مع مواجهة قرارات وأحداث شهرية عشوائية، وصولاً لتقييم نهائي يمنحك لقباً يعكس نمط حكمك.

## التشغيل

لا حاجة لأي تثبيت أو بناء - فقط افتح `index.html` في المتصفح، أو شغّل خادماً محلياً بسيطاً:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## البنية

- `index.html` - هيكل الشاشات
- `css/style.css` - التصميم (هوية بصرية ليبية، دعم كامل للعربية RTL)
- `js/data/` - بيانات اللعبة: السيناريوهات، القطاعات، القرارات، الأحداث، العلاقات
- `js/systems/` - المحركات: الاقتصاد، القرارات، الأحداث، العلاقات، نهاية اللعبة
- `js/state.js` - إدارة حالة اللعبة والحفظ/التحميل (localStorage)
- `js/charts.js` - رسوم بيانية بسيطة عبر Canvas
- `js/ui.js` - طبقة العرض
- `js/main.js` - المتحكم الرئيسي وحلقة اللعب الشهرية

## آلية اللعب

كل شهر لعبة: تحديث اقتصادي تلقائي (إيرادات النفط والضرائب، الإنفاق حسب توزيع الميزانية) → تقرير شهري → قرار أو قراران (استراتيجي/تكتيكي/دبلوماسي) → حدث عشوائي محتمل → تحديث المؤشرات. في بداية كل سنة تُعرض نافذة لمراجعة توزيع الميزانية.

تنتهي اللعبة عند إكمال 48 شهراً، أو عند انهيار الرضا الشعبي (انتفاضة)، أو الإفلاس الاقتصادي، أو انهيار الأمن (تدخل خارجي).

مبنية استناداً إلى وثائق تصميم اللعبة الخمس: وثيقة التصميم النهائية، النظام الاقتصادي، الخيارات الاستراتيجية وتأثيرات القرارات، النظام السياسي والعلاقات الدولية، ولوحة التحليلات والمؤشرات.
